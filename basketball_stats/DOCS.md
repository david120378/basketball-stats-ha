# Basketball-Stats

Die Seite ist nur über Home Assistant (Ingress) erreichbar, es wird kein Port nach außen geöffnet.
Die Daten liegen im Add-on-Speicher (`/data/data.json`) und sind im Home-Assistant-Backup enthalten.
Übernahme alter Daten: in der alten Seite „Sicherung (JSON)“ exportieren, hier „Importieren“ wählen.
